The guards

Each guard denies one class of command:

  • no-rm-tree: a recursive rm or find -delete outside a generated or agent-owned directory
  • no-git-footguns: add -A, commit -a, stash pop, force-push, reset --hard and the other moves that throw work away
  • no-delete-stacked-base: deleting a remote branch an open PR is based on (GitHub silently closes the PR)
  • issue-door: a second GitHub issue create, transfer or delete in one human turn, or any inside a loop
  • public-issue-guard: a term from your private list, posted to a public repo (off until you give it the list)
  • no-checkout-home: switching the branch checked out in $HOME, when home is itself a worktree (opt-in)
  • no-foreign-worktree: a command or edit that reaches into another session's git worktree (opt-in)
  • ask-first: a command the repo lists as costly, until you approve that one run
  • prose-budget-commit: a git commit whose staged prose runs over the repo's word budgets

Names link to the guard's own section where one exists (no-rm-tree, public-issue-guard, ask-first), else to the script. Opt-in is one word at the end. The scar stories move to the hook headers.
